# Stable Character Builder

Stable Character Builder is a platform-neutral Skill for designing, reviewing, revising, and structurally rebuilding one focal roleplay character.

It supports both lightweight edits and full architecture rebuilds. The architecture scales with the actual character problem: simple characters stay compact, while persistent state, information asymmetry, gates, beat logic, or other runtime machinery are added only when they have a concrete job. Rebuilds preserve canonical character content while separating Character, Runtime, and Scenario responsibilities.

The current public build also includes module-admission checks, design-time behavioral simulation, adversarial stress testing, root-cause playtest debugging, and an optional full Explicit Adult Scene Runtime. The adult module is binary rather than tiered: it stays uninstalled when detailed NSFW play is not wanted, and defaults to direct, specific physical detail when enabled. Its pattern grammar is used as author-side source material and compiled into character-specific behavior rather than pasted as a generic repertoire.

## Interaction-control placement

When a safeword or stop command is requested, ED contains the full operative rule; Intro may repeat a player-facing notice. Intro is capped at 2000 characters in the default five-file format; Greeting is not.


Full rebuild means the whole card may be reorganized, not that every mechanism must be installed. Light / Standard / Runtime-heavy architecture budgets keep structure proportional; adjacent functions may be merged, irrelevant ones stay absent, and long cards gain clearer semantic retrieval boundaries rather than simply more headings or prose. The delivery guard is intentionally lightweight and checks only high-cost failures.
